# Guide pilotage commercial V41 - Bizzi

La V41 ajoute un tableau de bord commercial dans l'espace administrateur.

## Objectif

Donner une vue rapide sur l'argent deja valide, l'argent a valider et les revenus minimums recuperables avec les relances d'abonnement.

## Ce qui change

- un bloc `Pilotage commercial` apparait sous les indicateurs admin ;
- il affiche les revenus encaisses ;
- il affiche les paiements a valider ;
- il estime le potentiel minimum des relances avec le forfait 1 mois a 999 FCFA ;
- il indique le taux de prestataires actifs ;
- il indique le service et la ville qui marchent le mieux ;
- il propose une action prioritaire ;
- le bouton `Copier bilan du jour` cree un resume pret a envoyer ou garder en note.

## Comment l'utiliser

1. Ouvrir `bizzi-app/admin.html`.
2. Deverrouiller l'admin.
3. Lire le bloc `Pilotage commercial`.
4. Commencer par l'action prioritaire :
   - valider les paiements si des paiements attendent ;
   - relancer les abonnements si des profils expirent ;
   - recruter plus de prestataires si tout est a jour.

## Conseil terrain

Tous les soirs, copier le bilan du jour et le conserver dans WhatsApp, Notes ou un fichier. Cela permet de suivre la progression de Bizzi sans outil payant au lancement.
