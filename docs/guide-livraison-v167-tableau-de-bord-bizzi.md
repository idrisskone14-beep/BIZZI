# Bizzi V167 - Tableau de bord réorganisé

## Objectif

Cette version réorganise l'accueil pour rendre l'application plus cohérente et plus facile à utiliser.

## Ce qui change

1. L'accueil commence par un vrai tableau de bord.
2. Les trois actions principales sont mises en avant :
   - Rechercher un service ;
   - Se faire livrer ;
   - Proposer vos services.
3. Les besoins rapides sont séparés :
   - Assistant Bizzi ;
   - Demande express.
4. Les opportunités locales sont regroupées :
   - Événements ;
   - Emplois & missions.
5. Les repères de confiance restent visibles sans encombrer l'écran.
6. Les services populaires, prestataires recommandés et événements à la une restent sous le tableau de bord.

## Test rapide

1. Ouvrir l'application.
2. Vérifier que le menu indique **Bizzi V167**.
3. Tester les trois grosses actions de l'accueil.
4. Tester Assistant Bizzi, Demande express, Événements et Emplois.
5. Vérifier l'affichage sur téléphone.

## Mise en ligne

1. Uploader le ZIP **V167** sur Cloudflare.
2. Faire **Purge everything**.
3. Rouvrir Bizzi sur téléphone.
