# Politique de confidentialité - Bizzi

Date : 8 juillet 2026

## Objet

Bizzi est une application de services géolocalisés. Les clients peuvent rechercher un service sans compte. Les prestataires, organisateurs et entreprises peuvent transmettre des informations pour être visibles dans l'application.

## Données collectées

Pour les clients :

- ville choisie ;
- position GPS si l'utilisateur l'autorise ;
- demandes express ;
- demandes de livraison ;
- avis, signalements et interactions de contact.

Pour les prestataires :

- nom ou nom commercial ;
- téléphone et WhatsApp ;
- métier ;
- ville, commune ou quartier ;
- description, photo, justificatifs éventuels ;
- statut d'abonnement, références de paiement et preuves transmises.

Pour les livraisons :

- point de départ ;
- point d'arrivée ;
- description du colis ;
- téléphone du demandeur ;
- distance estimée, montant, commission et statut de paiement.

Pour les emplois / missions :

- entreprise ou organisation ;
- contact ;
- métier recherché ;
- ville, description et référence de paiement.

Pour les événements :

- nom de l'événement ;
- organisateur ;
- contact ;
- ville, lieu, adresse, dates de début et de fin ;
- lien externe de billetterie ;
- statistiques de clics visibles dans Bizzi.

## Utilisation des données

Les données servent à :

- afficher des services proches ;
- publier des prestataires actifs ;
- traiter les validations admin ;
- gérer les paiements et abonnements ;
- affecter ou suivre des livraisons ;
- publier des offres et événements ;
- traiter les signalements ;
- améliorer la qualité du service.

## Géolocalisation

La géolocalisation est facultative. L'utilisateur peut choisir une ville manuellement. Si la position GPS est autorisée, elle sert à estimer la proximité des services, événements ou livraisons.

## Données publiques

Les informations d'un prestataire actif peuvent être visibles publiquement : nom commercial, métier, zone, description, photo et contacts. Si l'abonnement expire ou si le profil est suspendu, les contacts peuvent être masqués.

## Paiements

Bizzi peut conserver les références de paiement et les preuves transmises afin de vérifier une transaction ou traiter une réclamation. Les moyens de paiement externes restent soumis aux conditions de leurs opérateurs.

## Sécurité

Bizzi utilise des règles Supabase, un accès admin séparé, HTTPS via Cloudflare et des headers de sécurité. Les accès sensibles ne doivent jamais être partagés publiquement.

## Conservation

Les données sont conservées aussi longtemps que nécessaire pour fournir le service, respecter les obligations légales, traiter les litiges, les signalements ou les demandes de suppression.

## Droits

Un utilisateur ou prestataire peut demander la correction, la suspension ou la suppression de ses données lorsque cela est applicable.
