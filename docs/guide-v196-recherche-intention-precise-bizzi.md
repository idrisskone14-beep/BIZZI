# Bizzi V196 - Recherche précise et accueil simplifié

## Correction

La recherche Bizzi distingue clairement les intentions :

- événements ;
- emplois / missions ;
- livraison ;
- services prestataires.

## Accueil simplifié

L'assistant étant intégré directement dans Recherche / Services, l'écran principal ne répète plus les blocs "Prochain geste", "Besoin rapide" et l'onglet Assistant séparé.

## Exemple corrigé

```text
Recherche événement
```

Bizzi ouvre l'onglet Événements. Les prestataires comme Nounou ne sont plus mélangés.

## Autres exemples

- "concert à Abidjan" : filtre les événements Concert ;
- "emploi chauffeur" : ouvre Emplois / Missions ;
- "livreur de Cocody au Plateau" : ouvre Livraison et prépare la course ;
- "nounou à Cocody" : reste dans les services prestataires.
