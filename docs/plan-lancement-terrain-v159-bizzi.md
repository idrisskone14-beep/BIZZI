# Plan lancement terrain Bizzi - V159

Date : 8 juillet 2026

## Objectif

Tester Bizzi en conditions réelles avant une ouverture publique large.

## Zone pilote recommandée

Commencer avec une seule zone :

- Abidjan si l'objectif est volume ;
- Bouaké si l'objectif est test plus contrôlé ;
- Yamoussoukro si l'objectif est test institutionnel/étudiant.

## Échantillon

Recruter 10 à 20 prestataires :

- 2 plombiers ;
- 2 peintres ;
- 2 nounous ou aides à domicile ;
- 2 livreurs locaux ;
- 2 coiffeuses/coiffeurs ;
- 2 mécaniciens ;
- 2 imprimeurs ou événementiel ;
- 2 restaurants/hôtels ;
- 2 services administratifs ou visa ;
- 2 profils libres selon opportunité.

## Méthode

1. Inscrire les prestataires avec eux.
2. Vérifier leurs fiches côté client.
3. Demander à 10 clients de chercher un service.
4. Noter chaque blocage.
5. Tester un paiement prestataire.
6. Tester une livraison locale.
7. Tester une offre emploi.
8. Tester un événement.

## Indicateurs à suivre

- nombre de recherches ;
- nombre d'ouvertures de fiches ;
- nombre d'appels ou WhatsApp ;
- prestataires qui comprennent le paiement ;
- demandes de livraison complètes ;
- services les plus recherchés ;
- bugs ou incompréhensions ;
- temps nécessaire pour valider un paiement.

## Décision après 7 jours

Si les clients trouvent facilement un prestataire et si les prestataires acceptent le principe du paiement, élargir à une deuxième ville.

Si les utilisateurs bloquent souvent, corriger avant d'augmenter la communication.
