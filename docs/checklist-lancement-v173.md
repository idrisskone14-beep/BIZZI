# Checklist lancement Bizzi V173

## Tests avant ouverture publique

- Ouvrir Bizzi sur Android Chrome.
- Ouvrir Bizzi sur iPhone Safari.
- Installer la PWA sur écran d'accueil.
- Tester en Wi-Fi.
- Tester en 4G.
- Tester en réseau faible.
- Vérifier que l'écran ne reste pas blanc.

## Test client

- Rechercher un service sans inscription.
- Changer de ville.
- Ouvrir une fiche prestataire.
- Tester appel ou contact.
- Envoyer un avis.
- Créer une demande express.

## Test prestataire

- Créer un prestataire avec métier choisi.
- Vérifier que le mois gratuit est automatique.
- Vérifier qu'un doublon avec le même téléphone est bloqué.
- Identifier un prestataire existant.
- Créer un renouvellement forfait.
- Tester l'option boost.

## Test livraison

- Créer une livraison locale.
- Renseigner deux quartiers.
- Vérifier distance et tarif automatiques.
- Vérifier commission Bizzi 15%.
- Vérifier paiement en attente.
- Vérifier attribution livreur après paiement.

## Test admin

- Ouvrir le lien admin.
- Se connecter à Supabase.
- Charger validations.
- Vérifier Santé de l'application.
- Vérifier Prestataires à convertir.
- Valider un paiement.
- Retirer puis réactiver un prestataire.
- Exporter CSV prestataires et paiements.

## Test revenus

- Paiement forfait prestataire.
- Boost prestataire.
- Publication emploi.
- Promotion événement.
- Livraison avec commission.
