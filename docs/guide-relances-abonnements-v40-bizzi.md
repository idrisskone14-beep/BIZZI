# Guide relances abonnements V40 - Bizzi

La V40 ajoute une aide commerciale dans l'espace administrateur pour limiter les pertes apres l'essai gratuit ou a l'approche de l'expiration.

## Ce qui change

- la zone `Renouvellements proches` affiche un message de relance pret a envoyer ;
- le bouton `WhatsApp relance` ouvre WhatsApp avec le texte deja rempli ;
- le bouton `Copier message` permet de coller la relance dans un SMS, un appel note, Facebook, Instagram ou TikTok ;
- le bouton `Exporter CSV relances` cree un fichier avec les prestataires a relancer, leurs coordonnees, le statut et le message.

## Quand relancer

- 7 jours avant la fin de l'essai ou de l'abonnement ;
- le jour de l'expiration ;
- apres expiration, avant que le prestataire ne perde trop de clients.

## Message utilise

Le message rappelle que la visibilite Bizzi arrive a echeance ou est expiree, puis propose les forfaits :

- 1 mois : 999 FCFA ;
- 6 mois : 4 900 FCFA ;
- 12 mois : 9 900 FCFA.

## Conseil terrain

Commencer par WhatsApp pour les prestataires actifs, puis utiliser l'export CSV pour suivre ceux qui n'ont pas repondu.
