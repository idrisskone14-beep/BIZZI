# Politique de modération - Bizzi

Date : 8 juillet 2026

## Objectif

La modération Bizzi protège les clients, prestataires, livreurs, organisateurs et entreprises qui utilisent l'application.

## Contenus concernés

La modération peut concerner :

- profils prestataires ;
- demandes express ;
- livraisons ;
- offres emploi / missions ;
- événements ;
- avis clients ;
- signalements ;
- preuves ou références de paiement.

## Motifs de retrait ou suspension

Bizzi peut masquer, refuser ou suspendre un contenu en cas de :

- fausse information ;
- activité illégale ou dangereuse ;
- numéro de téléphone incorrect ;
- usurpation d'identité ;
- tentative de contournement de paiement ;
- comportement abusif ou harcèlement ;
- événement inexistant ou lien externe trompeur ;
- offre emploi frauduleuse ;
- demande de livraison risquée ou non conforme ;
- signalement grave non résolu.

## Prestataires

Un prestataire peut être :

- publié automatiquement pendant son essai gratuit ;
- retiré côté client par l'admin ;
- réactivé après correction ;
- flouté ou masqué en cas d'abonnement expiré ;
- suspendu en cas de risque ou de non-respect.

## Livraisons

Les demandes de livraison peuvent être refusées si le colis semble dangereux, illégal, non décrit ou si les informations de départ/arrivée sont insuffisantes.

## Événements

Bizzi ne vend pas les billets. L'admin peut refuser un événement si l'affiche, le lien, le lieu, la date ou l'organisateur semblent trompeurs ou incomplets.

## Emplois et missions

Les offres peuvent être refusées si elles sont discriminatoires, frauduleuses, dangereuses, non rémunérées de manière abusive ou insuffisamment décrites.

## Signalements

Un signalement peut être traité par :

- vérification des informations ;
- contact avec le prestataire ou l'organisateur ;
- correction d'une fiche ;
- suspension temporaire ;
- retrait définitif ;
- conservation d'une note admin.

## Délais

En phase de lancement, les traitements sont manuels. Les cas graves doivent être traités en priorité.
