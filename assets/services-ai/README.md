# Visuels métiers Bizzi V241

Cette bibliothèque contient 105 visuels originaux générés pour les 105 métiers du catalogue Bizzi. Les images Pinterest n'ont pas été copiées.

## Direction artistique

Illustration éditoriale premium semi-réaliste, professionnels africains en Côte d'Ivoire, action et outils exacts du métier, lumière cinématographique douce, accents bleu marine et orange, cadrage carré lisible sur mobile, sans texte, logo ni filigrane.

Chaque prompt complète cette direction commune avec le nom du service et une scène professionnelle dédiée. Exemple :

> Service : Plombier. Professionnel ivoirien réparant proprement le siphon d'un évier avec une pince adaptée et une caisse à outils.

## Performance

- Format : WebP, 640 × 640 maximum.
- Chargement : différé uniquement lorsque la carte apparaît.
- Cache : à la première consultation, jamais dans le préchargement initial.
- Connexion lente ou économie de données : illustration légère existante conservée, image premium non chargée.
- Convention de nommage : nom du métier normalisé en minuscules, sans accent, séparé par des tirets.
