# Bizzi V168 - Audit technique et nettoyage

## Objectif

Cette version stabilise le code sans modifier le visuel principal.

## Corrections techniques

1. Stockage local et session admin plus sûrs.
2. Initialisation plus tolérante si un élément HTML manque.
3. Suppression d'un rendu doublé.
4. Ajout d'un document d'audit technique.

## Test rapide

1. Uploader le ZIP V168.
2. Faire **Purge everything**.
3. Ouvrir Bizzi sur téléphone.
4. Tester Accueil, Services, Livraison, Prestataire, Événements, Emplois et Admin.
5. Vérifier que le menu affiche **Bizzi V168**.
