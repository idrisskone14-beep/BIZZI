# Règles livraison - Bizzi

Date : 8 juillet 2026

## Principe

Bizzi Livraison permet à un client de créer une demande de livraison locale. Le client ne voit pas directement les profils des livreurs locaux avant validation du paiement et affectation.

## Prix

Le prix est estimé selon :

- distance ;
- urgence ;
- heure de pointe ;
- conditions particulières ;
- montant minimum affiché dans l'application.

Bizzi peut conserver une commission de 15 % sur chaque livraison validée. Cette information reste visible dans l'administration, les exports, les règles et l'espace livreur/prestataire ; côté client, Bizzi affiche principalement le montant total de la livraison.

## Colis interdits

Sont interdits :

- produits illégaux ;
- armes ;
- substances dangereuses ;
- documents frauduleux ;
- argent liquide à transporter sans accord explicite ;
- tout colis non décrit correctement.

## Validation

Une demande devient exploitable après paiement ou validation admin. Le livreur reçoit les informations nécessaires uniquement après affectation.

## Réclamations

En cas de problème, Bizzi peut demander :

- référence de livraison ;
- numéro du client ;
- date et heure ;
- point de départ et destination ;
- preuve de paiement ;
- description du colis.

## Limite

Bizzi facilite la mise en relation et la traçabilité. Les responsabilités exactes doivent être précisées avec l'opérateur de paiement ou le partenaire logistique lorsque le service passe en production complète.
