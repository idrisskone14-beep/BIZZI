## Après le déploiement Cloudflare

1. Ouvrir `/admin`.
2. Dans « Données de test complètes », cliquer sur « Supprimer les données test ».
3. Cliquer sur « Créer toutes les données test ».
4. Revenir à l’accueil avec Abidjan sélectionné.
