# Règles événements - Bizzi

Date : 8 juillet 2026

## Principe

Bizzi sert uniquement à promouvoir les événements. Bizzi ne vend pas les billets, ne gère pas les remboursements et ne génère pas de QR code.

## Informations obligatoires

L'organisateur doit renseigner :

- nom de l'événement ;
- organisateur ;
- téléphone ou WhatsApp ;
- catégorie ;
- date de début ;
- date de fin ;
- lieu ;
- ville ;
- commune ou quartier ;
- adresse ;
- lien externe officiel d'achat ou d'information ;
- prix indicatif des billets si disponible.

## Visibilité géographique

Par défaut, un utilisateur voit les événements de sa ville. Un organisateur peut choisir un rayon de visibilité. Les événements sponsorisés doivent respecter la zone choisie.

## Formules

- Promotion standard : gratuit, visibilité simple après validation ;
- Boost 1 jour : 25 000 FCFA, visibilité sponsorisée dans la ville ou zone choisie ;
- Boost 1 semaine : 150 000 FCFA, visibilité sponsorisée dans la ville ou zone choisie ;
- Boost 1 mois : 3 000 000 FCFA, visibilité sponsorisée dans la ville ou zone choisie.

## Expiration

Un événement disparaît automatiquement après sa date de fin. Les statistiques de clics peuvent être envoyées à l'organisateur.

## Refus possible

Bizzi peut refuser un événement si :

- le lien externe est douteux ;
- le lieu ou la date est incomplet ;
- l'affiche est trompeuse ;
- l'organisateur n'est pas identifiable ;
- l'événement présente un risque ou viole les règles locales.
