# Bizzi V202 - Livraison claire côté client

## Départ depuis la position actuelle

Le client peut utiliser sa position GPS comme point de départ d'une livraison.

## Affichage client

L'interface client affiche principalement :

- le montant total à payer ;
- le trajet ;
- le statut de la commande ;
- la référence de paiement ;
- l'attribution du livreur après acceptation.

La commission Bizzi et la part livreur restent gérées côté logique interne, administration, export, règles et espace livreur/prestataire.
