# Bizzi V173 - Pré-lancement public

V173 ajoute un pilotage plus professionnel avant ouverture large :

- santé de l'application ;
- prestataires à convertir en payant ;
- livraison plus lisible ;
- anti-doublon renforcé ;
- diagnostics Supabase ;
- checklist terrain ;
- procédures externes.

SQL à exécuter après V172 :

1. `75-diagnostic-global-rapports-v173.sql`
2. `76-nettoyage-doublons-prestataires-v173.sql`

Dans l'admin, commencez par Santé de l'application puis Prestataires à convertir.
