# Sécurité et stabilité V301

- Une référence de transaction ne peut pas créer plusieurs renouvellements locaux.
- Une validation répétée ne prolonge pas deux fois le même paiement.
- Les données restent localement récupérables si le réseau tombe.
- La confirmation indique une référence de dossier et l'état de synchronisation.
- Les boosts expirent automatiquement selon leur durée validée.
