# Politique de confidentialité Bizzi V178

Bizzi collecte uniquement les informations nécessaires au fonctionnement des services : nom, téléphone, ville, quartier, métier, description, images fournies volontairement, demandes de livraison, offres emploi, événements et actions de contact.

Les clients peuvent rechercher un service sans inscription obligatoire. Les prestataires et organisateurs fournissent leurs informations pour être visibles dans l'application.

Les données de paiement conservées par Bizzi servent à la traçabilité : moyen de paiement choisi, forfait, montant, référence de transaction et statut de validation. Bizzi ne conserve pas les codes secrets mobile money.

Pour les événements, Bizzi ne vend pas les billets. Le client est redirigé vers le contact ou le lien officiel fourni par l'organisateur.

Les données peuvent être utilisées pour :

- afficher les prestataires et services ;
- traiter les validations admin ;
- prévenir les doublons et abus ;
- améliorer la sécurité ;
- produire des statistiques internes ;
- gérer les réclamations.

Les informations sensibles doivent être protégées dans Supabase et Cloudflare. Aucune clé secrète ne doit être placée dans l'application publique.

Pour toute demande liée aux données : contact@bizzi-africa.com.
