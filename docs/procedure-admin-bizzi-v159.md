# Procédure admin Bizzi - V159

Date : 8 juillet 2026

## Routine quotidienne

1. Ouvrir le lien admin officiel.
2. Se connecter à Supabase avec le compte admin.
3. Cliquer sur `Charger validations Supabase`.
4. Traiter les paiements en attente.
5. Vérifier les prestataires récents.
6. Traiter demandes express, livraisons, emplois et événements.
7. Exporter les données si une sauvegarde est nécessaire.

## Prestataires

### Nouveau prestataire

1. Vérifier nom, téléphone, métier, ville et quartier.
2. Confirmer que le profil apparaît côté client.
3. Si le profil est problématique, utiliser `Retirer côté client`.
4. Si le profil est corrigé, utiliser `Réactiver côté client`.

### Paiement forfait

1. Contrôler la référence de paiement.
2. Vérifier le montant attendu.
3. Valider Supabase si le paiement est conforme.
4. Recharger le public.
5. Vérifier que l'abonnement est prolongé.

## Livraisons

1. Vérifier départ, destination, téléphone et colis.
2. Confirmer que le montant et la commission 15 % sont cohérents.
3. Valider le paiement.
4. Affecter ou confirmer le livreur disponible.
5. Garder la référence en cas de réclamation.

## Emplois / missions

1. Vérifier entreprise, contact, ville et métier recherché.
2. Contrôler la référence de paiement.
3. Publier si l'offre est claire et conforme.
4. Refuser ou archiver si elle est trompeuse.

## Événements

1. Vérifier nom, organisateur, téléphone, ville, lieu, adresse.
2. Contrôler date de début et date de fin.
3. Vérifier le lien externe de billetterie ou d'information.
4. Publier si l'événement est fiable.
5. À la fin, envoyer les statistiques à l'organisateur si nécessaire.

## Signalements

1. Lire le motif.
2. Vérifier la fiche concernée.
3. Contacter le prestataire si besoin.
4. Corriger, flouter, suspendre ou clôturer.
5. Noter la décision dans les exports ou le suivi admin.

## Règle simple

En cas de doute sérieux : retirer temporairement côté client, vérifier, puis réactiver seulement après correction.
