# Fiche Play Store / App Store Bizzi

## Nom

Bizzi

## Sous-titre

Trouvez. Réservez. Réalisez.

## Description courte

Bizzi aide à trouver rapidement des prestataires, livraisons, événements et opportunités proches de vous.

## Description longue

Bizzi est une application de services pensée pour la Côte d'Ivoire et l'Afrique. Les clients peuvent rechercher un prestataire sans créer de compte, consulter les services disponibles par ville et contacter les professionnels visibles sur Bizzi.

Les prestataires peuvent proposer leurs services, bénéficier d'un mois gratuit, puis renouveler leur visibilité avec un forfait. Bizzi propose aussi des demandes express, des livraisons locales, des offres d'emploi/missions et la promotion d'événements.

Bizzi ne vend pas les billets d'événements. Bizzi redirige vers les canaux officiels de l'organisateur.
