# Pack lancement Bizzi V181

## Objectif

Ouvrir Bizzi progressivement avec un petit groupe réel, mesurer les erreurs et convertir les premiers prestataires payants.

## Ordre recommandé

1. Uploader le ZIP V181.
2. Purger Cloudflare.
3. Exécuter les scripts SQL jusqu'au SQL 77 si ce n'est pas encore fait.
4. Ouvrir l'admin avec le lien sécurisé.
5. Importer le catalogue public.
6. Charger les validations Supabase.
7. Vérifier le panneau `Prêt / Pas prêt pour lancement`.
8. Remplir la checklist V181.
9. Tester Android, iPhone et réseau faible.
10. Ouvrir à 20 à 50 utilisateurs pilotes.

## Indicateurs à surveiller

- prestataires visibles ;
- prestataires à relancer ;
- paiements en attente ;
- revenus potentiels ;
- livraisons payées à dispatcher ;
- erreurs visibles admin ;
- offres emploi en attente ;
- événements en attente.

## Relances rentabilité

Priorité aux prestataires :

- proches de la fin d'essai ;
- ayant reçu des contacts ;
- dans les métiers recherchés ;
- visibles sans paiement récent ;
- candidats à un boost.

## Message court

Bonjour, Bizzi vous donne de la visibilité auprès des clients de votre zone. Votre profil peut rester visible avec un forfait simple et un boost si vous voulez ressortir davantage.
