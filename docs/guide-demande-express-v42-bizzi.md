# Guide demande express V42 - Bizzi

La V42 ajoute une fonction centrale pour rendre Bizzi plus indispensable : la demande express.

## Pourquoi c'est important

Un client ne sait pas toujours quel prestataire appeler, surtout en cas d'urgence. Avec la demande express, il peut simplement decrire son besoin sans creer de compte. Bizzi propose ensuite les prestataires actifs les plus pertinents et prepare le message WhatsApp.

## Ce que le client peut faire

- choisir un service ;
- indiquer sa ville, commune ou quartier ;
- preciser l'urgence ;
- decrire le besoin ;
- ajouter son telephone ou WhatsApp s'il veut ;
- envoyer un message deja prepare a un prestataire ;
- copier le message pour l'envoyer ailleurs.

## Ce que l'admin voit

Dans l'espace administrateur, un nouveau bloc `Demandes express clients` affiche :

- le service demande ;
- la zone ;
- l'urgence ;
- le message du client ;
- le contact client si renseigne ;
- un bouton pour copier la demande ;
- un bouton pour revoir les prestataires recommandes ;
- un bouton pour marquer la demande traitee.

## Export

Le bouton `Exporter CSV demandes` permet de recuperer toutes les demandes express pour analyser les vrais besoins du marche.

## Impact business

Cette fonction transforme Bizzi en assistant de recherche, pas seulement en annuaire. Elle aide a comprendre quels services sont le plus demandes et dans quelles zones il faut recruter plus de prestataires.
