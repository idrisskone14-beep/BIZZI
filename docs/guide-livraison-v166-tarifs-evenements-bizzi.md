# Bizzi V166 - Tarifs événements

## Objectif

Cette version met à jour les formules de promotion des événements.

## Nouveaux tarifs

- Promotion standard : gratuit.
- Boost 1 jour : 25 000 FCFA.
- Boost 1 semaine : 150 000 FCFA.
- Boost 1 mois : 3 000 000 FCFA.

## Ce qui change

1. Dans **Événements**, ouvrir **Promouvoir votre spectacle**.
2. Les quatre formules ci-dessus apparaissent dans **Forfait promotion Bizzi**.
3. Les boosts affichent la durée correspondante dans les instructions de paiement.
4. Les règles événements et les conditions d'utilisation ont été mises à jour.

## Important

Bizzi ne vend toujours pas les billets. Les paiements concernent uniquement la visibilité de l'événement dans l'application.

## Mise en ligne

1. Uploader le ZIP **V166** sur Cloudflare.
2. Faire **Purge everything**.
3. Rouvrir Bizzi sur téléphone.
4. Vérifier que le menu indique **Bizzi V166**.
