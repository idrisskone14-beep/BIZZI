# Bizzi V195 - Recherche par intention précise

## Correction

La recherche Bizzi distingue maintenant clairement :

- événements ;
- emplois / missions ;
- livraison ;
- services prestataires.

## Exemple corrigé

```text
Recherche événement
```

Bizzi ouvre l'onglet Événements et affiche les événements disponibles. Les prestataires comme Nounou ne sont plus mélangés.

## Autres exemples

- "concert à Abidjan" : filtre les événements Concert ;
- "emploi chauffeur" : ouvre Emplois / Missions ;
- "livreur de Cocody au Plateau" : ouvre Livraison et prépare la course ;
- "nounou à Cocody" : reste dans les services prestataires.
