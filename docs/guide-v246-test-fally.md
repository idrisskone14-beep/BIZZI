## Activer le scénario

1. Ouvrir `/admin`.
2. Dans « Données de test complètes », supprimer les anciennes données test.
3. Cliquer sur « Créer toutes les données test ».
4. Revenir à l’accueil avec la ville Abidjan sélectionnée.
