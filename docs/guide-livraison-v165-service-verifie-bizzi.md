# Bizzi V165 - Service vérifié plus visible

## Objectif

Le filtre **Vérifiés seulement** était trop discret dans l'onglet **Recherche service**. Cette version le transforme en encart visible.

## Ce qui change

1. Un bloc **Service vérifié Bizzi** apparaît sous la barre de recherche.
2. Le bouton **Afficher les vérifiés** est plus grand et plus clair.
3. Le compteur indique combien de prestataires vérifiés sont disponibles.
4. Quand le filtre est actif, le bloc change de couleur et affiche **Filtre vérifié activé**.
5. Le rendu est adapté au téléphone.

## Test rapide

1. Ouvrir **Services**.
2. Vérifier que le bloc **Service vérifié Bizzi** est visible.
3. Cliquer **Afficher les vérifiés**.
4. Vérifier que seuls les profils vérifiés apparaissent.
5. Cliquer **Tout afficher** pour revenir à la liste complète.

## Mise en ligne

1. Uploader le ZIP **V165** sur Cloudflare.
2. Faire **Purge everything**.
3. Rouvrir Bizzi sur téléphone.
4. Vérifier que le menu indique **Bizzi V165**.
